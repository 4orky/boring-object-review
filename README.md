A single funny, honest line about the dullest everyday object in the house — the dustpan, whose one talent is leaving a grey line behind. Running the program writes that line to `/output/entry.txt`:

> The dustpan has one job — catch the dust — and it still
> leaves a thin grey line behind every single time, like a signature.

## How to run it

Run it with `python3 main.py` from this folder; it prints the winning line and writes the same text to `/output/entry.txt`.

The program reads the file back after writing and checks the text plus its SHA-256 digest, so a partial write fails loudly instead of submitting a broken entry.
